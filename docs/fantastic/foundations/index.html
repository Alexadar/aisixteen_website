Aisixteen Fantastic

Foundations

How Fantastic works underneath, one mechanism at a time, in five parts. Each page follows the code on the main branch of the open-source repo, for the Rust and Python runtimes, with short animations of the mechanism it describes.

  1. Part 1 · 8 articles · 8 published

    Protocol

    One message model shared by humans, models and programs: verbs, batch send, the two-sided call gate, security, refusals, the ledger, transports and the shared contract.

    Read →
  2. Part 2 · 5 articles · 5 published

    Kernel

    The runtime that holds agents and routes messages: records in one tree, their lifecycle, bundles in Rust and Python, tasks and waiting, and what survives a restart.

    Read →
  3. Part 3 · 12 articles · 12 published

    Agents

    The agents fantastic ships, grouped by what they do: the AI agent and its memory, credentials, IO legs for files, commands, the web, other kernels and MCP, program agents, kernel services and team spawning.

    Read →
  4. Part 4 · 10 articles

    Canvas: an app built on fantastic

    The browser canvas as an application made of agents: a page kernel bridged to the host, cells that are views of agents, nested canvases and the grants between them.

    Read →
  5. Part 5 · 4 articles

    Build your own

    A bundle is code, an agent is an instance of it: folder bundles, program agents, views, and a product built on fantastic.

    Read →

Every page follows the source on the main branch of github.com/aisixteen/fantastic and names the files it draws on. The animations are rendered with Manim from scripts kept next to this site’s source; ids and agent names in them are illustrative.
